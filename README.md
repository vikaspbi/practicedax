# PracticeDAX

Practice DAX formulas and learn Power BI concepts with domain sample data — calculated columns, measures, challenges, and guided lessons.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## GitHub Pages

Live site: [https://vikaspbi.github.io/practicedax/](https://vikaspbi.github.io/practicedax/)

```bash
npm run build:pages
```

Static files are written to `out/`. On pushes to `main`, GitHub Actions builds and deploys Pages automatically.

In the repo **Settings → Pages**, set Source to **GitHub Actions** (or the `gh-pages` branch).

## Features

- Domain sample models (Sales, HR, Finance)
- Interactive DAX lab for measures and calculated columns
- Challenges with hints and solutions
- Power BI concept lessons
